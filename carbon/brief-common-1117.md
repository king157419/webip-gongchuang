# 任务：给"上海大学人工智能社"官网做一个"滑动即交互"的新版本（单页）

## 背景
社团负责人看了两个参考站后说："我要的就是这个效果……视觉效果、交互效果，这就是我想要的。而且它又不算是花里胡哨，恰恰好，炫酷带来的是交互。"截止时间很紧，你这一版要一次做到能直接上线的完成度。

参考站（你可以联网看；看不了就按下面的描述来）：
- topology.vc：浅灰带胶片颗粒的首屏；超大细字（"Meet us at"）逐词缓慢浮现；一个 WebGL 的地形/等高线曲面，边缘是彩虹薄膜色的细线，带颗粒；鼠标经过时曲面跟着起伏；往下滚动时镜头俯冲穿过地形；之后是深色（#151515 左右）分区，大字号标题、横向平移的卡片、灰度人物照片网格。配色克制，动作慢、重、缓动顺滑。
- shopify.design：白底，超大粗体字逐字拼合入场；首屏有可以用鼠标/手指拖动、甩出去、带物理回弹的立体小物件；作品卡片瀑布流随滚动浮现；有吸顶的滚动段落（滚动时数字、刻度在变）；可以横向拖着滑的彩色大卡；黑色粗字配几种明亮强调色。

"质感"是关键：动效和交互是给访客的手感和惊喜，不是让访客完成一个任务。

## 这一轮的核心：把"必须的滑动"变成交互（最重要，先读懂）
负责人看完 v14（玩具盒）、v15（立体小智）后说：首屏再炫，下面还是一栏一栏平铺，来访者一划而过什么都没记住。他的判断是：**唯一的解法，是把来访者本来就必须做的滑动动作，直接变成交互**（他举的例子是"甚至可以变成切水果"）。

所以这一版的硬要求：
1. **滑动就是操作**。页面主体用"吸顶舞台"（`position: sticky` 的全屏舞台 + 外面一段足够高的滚动轨道），用原生滚动的进度驱动舞台里的动作。每往下滑一段，就完成一个看得见的动作（切开、焊上、去噪……），动作的结果就是这一节的内容。
2. **一节一拍，停得住**。每一节分三段：动作（约占这一节滚动距离的 40%）→ 停住可读（约 45%，内容完全静止、完整显示）→ 过渡到下一节（15%）。滑得再快，内容也会在"可读段"完整出现；往回滑，动作倒放。
3. **不劫持滚动**。不准 `preventDefault` 滚轮或触摸、不准自己接管滚动、不准 scroll-snap 强制吸附。手机上手指正常滑就行。键盘（空格、方向键、PageDown）照样能翻。
4. **不挡信息**。访客什么都不做、只是一路往下滑，也能看完全部内容。额外的手势（比如用鼠标/手指划过物体）只是加分彩蛋，不是必须。首屏不滑也要 1 秒内看到社团名、一句话说明和"怎么加入"的入口。
5. **内容要砍**。一共 5–6 拍：①社团是什么（首屏）②平时做什么（5 种活动，每种一句话）③做过的事（从 16 篇报道里挑 4–5 条最有分量的，再给一个"全部 16 篇"的展开列表或链接）④谁在带大家 ⑤怎么加入。每拍屏幕上的字控制在 60 字以内（列表除外）。
6. **右侧或底部要有进度**，例如"3 / 5"或一排小刻度，让访客知道还剩多少；点刻度能跳到那一拍（用 `scrollTo` 平滑滚到对应位置）。
7. **`prefers-reduced-motion: reduce` 或舞台初始化失败时**，退回成普通的分节页面，所有内容照常可读。
8. 动作要让人"感到是自己造成的"：动作的进度严格跟手（跟滚动进度一一对应，可加很短的缓动），有声势（碎片、光、形变、数字跳动），但收尾干净，内容出现后背景安静下来。

## 硬约束
- 纯原生 HTML/CSS/JS，**不要引用任何外部 CDN**（校园网 + 国内手机）。需要 WebGL 就手写 WebGL1。自己写的 JS 总量 70KB 以内（不压缩）。
- 手机优先：375 宽必须好看、能用，触摸能交互，没有横向页面滚动；桌面 1440 宽要有大气的版式。
- 性能：动画只用 transform/opacity 或 canvas；WebGL 画布 devicePixelRatio 上限 1.5（手机 1）；画布不在视口或页面隐藏时停止渲染；`prefers-reduced-motion: reduce` 时关掉连续动画给静态帧；WebGL 拿不到时有 CSS 兜底，页面照常可读。
- 入场动画必须有不依赖 requestAnimationFrame 的兜底（例如 2.5 秒后 setTimeout 把所有元素直接放到最终位置），否则后台标签页里会卡在半路。
- 首屏 1 秒内能看到社团名和一句话说明。
- 可访问：语义标签、按钮可键盘操作、对比度够、图片有 alt。
- `<title>`：上海大学人工智能社。favicon：`../shared/img/ip/zhi-flat.webp`。css/js 链接带 `?v=1` 版本号；多个 js 文件时总量仍在 70KB 内。
