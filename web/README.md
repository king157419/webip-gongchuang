# 上海大学人工智能社官网：三套方案

三套方案共用同一份内容数据 `shared/content.js`，视觉和信息组织各不相同，选定一套后可单独打包提交。

| 方案 | 目录 | 风格 | 搭配 IP | 页面组织重点 |
| --- | --- | --- | --- | --- |
| 一「蓝图」 | `v1-blueprint/` | 普鲁士蓝工程图纸，白色线稿，尺寸标注 | 小智 | 时间轴（2021→2026 真实活动按比例排布）、活动登记表、新闻按类型筛选 |
| 二「贴纸」 | `v2-sticker/` | 暖白纸面，模切白边与硬投影，活泼 | 元元 | 招新优先：数据卡片、“一次焊接课长什么样”、部门选择器 |
| **五「小智·焦点」（新）** | `v5-zhi/` | 首屏只有一个焦点：小智站在中间、关键信息像标签一样贴在周围、黄色“我想加入”按钮在它脚下；下面一排大数字；活动、新闻都用列表排，一眼能扫完 | 小智 | 参考 TreeHacks、CalHacks、MLH、Recurse Center 等学生技术社区网站 |

| 三「社刊」 | `v3-riso/` | 孔版印刷社刊“通通快报”，蓝 + 珊瑚两色 | 通通 | 新闻优先：头版头条、新闻存档（年份筛选 + 关键词搜索 + 高亮） |

## 首页导流（2026-11-08 修改）

问题：首页把简介、活动、新闻、人物、荣誉、加入按同样的分量平铺，访客打开后不知道该先看哪里。
改法（三套方案共用 `shared/guide.js`，样式各自适配）：

- 首屏只保留一句标题、一段话和一个主按钮，去掉并列的第二个按钮。
- 首屏下方放三个“入口”，按访客目的分流：**第一次来，怎么加入？**（主入口，最醒目）、**社团最近在做什么？**、**谁在带大家？** 入口里的数字（报道数、最近一篇的月份、人物人数）都从 `content.js` 计算。
- 新闻首页只先显示 3–4 条，按钮写明“再看几条（共 N 条）”。
- 手机端：缩小首屏形象图，保证主入口在第一屏内（375 × 812 下已核对）；滚过首屏后右下角常驻“加入我们”按钮，到加入版块自动隐藏。

## 本地预览

静态网站，无需构建。任选其一：

```bash
python -m http.server 8848 --directory web
```

然后打开 `http://localhost:8848/v5-zhi/`（或 `v4-zhi/`、 `v1-blueprint/`、`v2-sticker/`、`v3-riso/`）。也可部署到 GitHub Pages / Gitee Pages / 任意静态托管。

## 日常更新（给社团维护同学）

**只需要改 `shared/content.js`**，页面会自动重新渲染：

- 发新闻：在 `news` 数组最前面加一条 `{ date, cat, title, summary, source }`，`cat` 取 `weld / course / visit / contest / talk`。
- 补人物照片：照片放进 `shared/img/`，在 `people` 对应条目里填 `photo: "文件名"`；`desc` 填介绍。
- 开放报名：把 `join.formUrl` 改成问卷链接，`join.season` 填招新时间，三套方案的报名按钮会自动启用。
- 值为 `null` 的字段（成员人数、联系方式等）会显示“待社团补充”标签，不会出现空白或编造的内容。

## 内容来源与核实原则

- 社团信息、人物资料来自主办方资源包。人物只展示社团确认的社长任捷、指导老师吴静和张恒（资料出自资源包中的年审与申报材料）；资源包里“原企划”的 12 人名单经社团确认不是实际成员，已不再展示。
- 16 条新闻全部整理自上海大学通信与信息工程学院官网（同步自学院公众号）的公开报道，标题、日期与原文一致，每条附原文链接；只收录与人工智能社直接相关的报道。
- “荣誉与成果”只列原文明确写明社团承办、协办的事项；个人竞赛奖项只放在对应人物介绍中，不写成社团成果。
- 新闻原图未收录：学院网站禁止程序下载图片，因此相关位置使用 IP 形象，或保留占位交给社团补充。

## 设计方法与第三方资源

- 设计规范参考开源项目 [Hallmark](https://github.com/nutlope/hallmark)（MIT，约 3 万 star 的“反 AI 模板感”设计技能），按其规则手工执行：颜色与字体全部走 CSS 变量、禁用紫蓝渐变 / 卡片套卡片 / emoji 图标、首屏在 1280×800 内完整显示标题与行动按钮、所有交互元素有键盘焦点样式、尊重“减少动态效果”系统设置、不编造任何数字与评价。三套方案分别取用了它的 blueprint、sticker、riso 主题思路，并按社团 IP 重新配色。
- 字体：Noto Sans SC、Noto Serif SC、ZCOOL QingKe HuangYou、Chakra Petch、IBM Plex Mono，均来自 Google Fonts，SIL Open Font License。
- 学院字标、社团原 Logo 来自主办方资源包。

## AI 协作说明

**使用的工具与环节**

1. Claude（Claude Code）：解读赛题与资源包；检索网页设计方法与开源方案；从学院官网整理新闻；编写三套网站的 HTML / CSS / JS；在浏览器中逐屏检查桌面与手机端效果并修复问题。
2. Codex（内置图像生成）：生成网站使用的社团 IP 形象图（详见 IP 赛道说明）。
3. 人工：确定三套方案的方向与栏目结构、核对新闻内容与人物名单口径、决定哪些信息标注“待补充”。

**典型修改案例：网站文字的“AI 味”（方案四）**

- 原始输出：方案二的文案里有不少说明性的话，比如“根据某某报道整理”“内容整理自……点卡片可读原文”、数字下面标“来源：”，标题用了装饰性很强的站酷庆科黄油体，正文是 AI 生成网页几乎都会用的思源黑体（Google Fonts 版）。
- 调整方案：方案四把这些对访客没用的说明全部删掉，来源改为每条新闻直接链接原文；文案改成社员口吻（“从焊好第一个焊点开始”“有想办的活动？”）；字体不再加载网络字体（站酷庆科黄油体、思源黑体 Noto Sans SC、像素字体都去掉），改用系统自带的苹方 / 微软雅黑——学院官网用的就是微软雅黑。第一稿方案四还重新设计了版式，社员反馈不如方案二清楚，于是第二稿直接沿用方案二的版式，只换配色和吉祥物（第一稿保留在 `_old/v4-zhi-draft1/`）。
- 修改原因：社团成员试看后觉得“一股 AI 味”。官网是写给新同学看的，解释“这段文字是怎么来的”只会打断阅读；核验来源靠原文链接就够了。

**典型修改案例一：首页没有焦点**

- 原始输出：首页按版块平铺七八块内容，分量相同，首屏有两个并列按钮。
- 调整方案：首屏下加三个按访客目的分流的入口，主入口突出；新闻默认少显示几条；手机端常驻“加入我们”。
- 修改原因：试看时发现访客“无从下手就退出了”；官网的首要任务是让新同学找到加入方式，其次才是浏览内容。

**典型修改案例二：时间轴文字**

- AI 原始输出：方案一的时间轴最初用代码自动截取新闻标题作为节点文字，结果出现“联合2021级通信1班团支部举办”这类截断的半句话；最后三个节点挤在一起，互相重叠。
- 调整方案：改为在数据里为每个节点手写简短标签（如“承办昇思训练营”“近百人走进鸿蒙生态学堂”），并删去挤在末端的 2026 年 5 月节点，保留 7 个代表性节点。
- 修改原因：时间轴的作用是让新同学一眼看懂社团做过什么，自动截断的标题既读不通又难看；节点重叠在手机上更无法阅读。

其他按规范做的修改：去掉了首屏标题上方的小字标签（Hallmark 规则中的“眉题”模板感），页脚中用“·”拼接的说明改为完整句子；方案三的人物版曾因重复的元素 id 导致三栏变成一栏，检查截图时发现并修复。
