# Web 内容整理说明

## 已提供的内容
社团基本信息、简介、原企划中完整的社长及副社长、指导老师与顾问老师名单和介绍，以及其他材料的人物补充记录、任捷活动照片、现有社团标识与学院字标。原企划12人名单见“原企划师生人物完整名单.md”，并提供人物资料.json 便于导入。

## 由参赛者自行整理的内容
新闻动态、社团活动、荣誉成果及其他公开信息，自行到上海大学通信与信息工程学院公众号搜集整理，优先采用与人工智能社直接相关的推文。

每条内容请保留文章标题、发布日期和原文链接，方便主办方核验；正文可提炼整理，人物、时间、活动名称及获奖情况应与原文一致。对于原文仅涉及学院、未表明与社团关联的成果，不要改写成社团成果。

资料未覆盖的人物介绍、任期和照片可由社团后续补充；制作期间可以使用明确标注的占位内容，不虚构真实经历或身份。

## 视觉参考
本目录标识供网站设计参考。页面布局、配色、交互和技术方案可自由设计。
