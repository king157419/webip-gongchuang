## 一、打开方式与压缩包目录说明

本作品为上海大学人工智能社官方网站，采用**纯静态前端页面 + 独立单文件数据源**架构，无需安装任何运行环境即可在本地直接打开浏览：

1. **本地双击直接打开（推荐评委使用）**：
   - 将压缩包完整解压到本地任意文件夹（不要直接在压缩软件预览窗口里双击，否则浏览器读不到同目录的图片、字体和数据文件）；
   - 双击解压目录最外层的 **`index.html`（本地入口页）**，点击页面上的卡片即可直接进入本次主参评版本 `【待定：v?】/index.html`；也可以直接打开 `【待定：v?】` 文件夹双击里面的 `index.html`。
   - 网站已完成**电脑宽屏（1440px）与手机窄屏（375px）双端响应式适配**，可在浏览器开发者工具切换手机宽度或缩放窗口直接检验，无横向滚动条破版。
2. **本地静态服务预览（可选）**：
   - 若希望模拟线上服务器路径，可在解压根目录运行 `python -m http.server 8848`，浏览器访问 `http://localhost:8848/`。
3. **压缩包内文件结构**：
   - `index.html` + `_thumbs/`：根目录入口引导页与首屏缩略预览图，双击即可点击进入主参评官网页面；
   - `【待定：v?】/`：本次正式提交参评的社团官网源码目录（手写原生 HTML、CSS、JavaScript）；
   - `shared/`：全站共用的唯一内容数据文件 `shared/content.js`、本地按需分片字库与开源字体许可协议 `shared/fonts/`、社团标识与原创吉祥物图片素材 `shared/img/`；
   - `作品说明.md`（即本文档）：运行方式、六大板块对照、维护机制、AI 辅助创作说明与第三方素材来源声明。
   - *补充提示*：官网页脚保留的「管理后台（`/admin/`）」小链接用于部署到线上服务器后登录内容后台；在本地离线双击打开文件时，浏览器无法跳转该服务端路径属于正常现象，不影响官网前台全部功能浏览。

## 三、技术方案、日常迭代维护与后台设计

1. **纯原生零外链前端，断网与校园网均可秒开**：
   - 全站采用手写原生 `HTML5 + CSS3 + JavaScript` 编写，未引入庞大前端框架、打包构建工具或任何外部公共 CDN 链接，评委离线双击即可完整运行。
   - 交互探索版本按各自主题使用原生 `Canvas 2D`、手写轻量二维刚体物理碰撞或原生 `WebGL 1.0` 着色器实现动效，并做了严格性能与容错保护：限制高分屏画布像素比、滚出视口或切后台自动暂停渲染、入场动画设超时硬兜底防止页面卡白屏；当访客系统开启「减少动态效果（`prefers-reduced-motion`）」或浏览器不支持 WebGL 时，自动降级为干净可读的静态版式。
   - 全站动态拼接内容均做 HTML 字符转义，提供「跳到正文」无障碍跳转、语义化标签与清晰的键盘焦点边框。
2. **本地按需分片中文字库（`shared/fonts/`）**：
   - 标题使用的思源宋体整套字库原本在十兆字节以上。团队编写了 `shared/fonts/build_fonts.py` 切字脚本（基于 `fontTools`），将可变字体提取出 200 / 400 / 900 三个字重：先把官网现有文字全部打进第 0 号分片（单片仅约 240–260 KB），再把其余 GB2312 常用汉字按每 350 字切成后续分片（共 57 个 `.woff2` 汉字分片 + 1 个 `GeistMono-latin.woff2` 西文数字分片），通过 `fonts.css` 的 `unicode-range` 按需加载。平时打开只下首片，日后社团更新新闻用到新字时浏览器才自动补下对应小分片。
3. **换届零代码门槛的两种更新方式**：
   - **方式一（纯静态单文件更新，适合本地托管或静态空间）**：社团学弟学妹换届后无需改动任何网页代码，只需用任意文本编辑器打开 **`shared/content.js`**，按文件顶部中文注释在 `news` 数组最前面新增一条新闻、修改 `people` 人物介绍或填入 `join.formUrl` 问卷链接，保存后全站页面自动重新排版渲染。
   - **方式二（配套轻量级网页管理后台，适合云服务器长期运行）**【待确认：本次提交压缩包默认只打包纯静态前端以保证评委双击即看、零环境依赖；若决定同时附带脱敏后的 `server/` 后台源码，请同步修改本段括号说明】：团队另行开发了配套管理后台 `club_admin`（基于 Python `FastAPI + Uvicorn + SQLite` 标准库，前端为原生无内联脚本页面）。在线上服务器运行时：
     - 管理员在 `/admin/` 登录后即可通过可视化表单增删新闻、活动、荣誉、人物和招新问答，支持图片上传（校验文件头魔数防伪造）、最近 100 份历史版本差异对比与一键回滚、最近 300 条操作审计记录；
     - 管理员账号仅限在服务器终端交互创建，密码采用 `scrypt` 随机加盐哈希存储，配备同 IP 连续失败 5 次锁定 10 分钟、写接口同源校验与 `SameSite=Strict` 会话保护；
     - 后台按最新 `content.json` 动态生成带缓存协商头的 `/shared/content.js`；即使后台服务故障，也会按「内存上一份有效数据 → 历史快照 → 静态兜底 `shared/content.js`」三级自动回退，确保社团官网永远正常可看。

## 五、典型修改案例：去掉网页「机器说明书腔」，重做首屏焦点导流与本地分片字库

- **1. AI 原始输出是什么样**：
  早期由 AI 生成的网页稿（留存于仓库 `v2-sticker` 及旧稿 `_old/v4-zhi-draft1`）暴露出三处明显的「机器生成模板感」：
  - **满屏交差式套话**：正文多处夹杂「根据某某报道整理」「内容整理自……点卡片可读原文」，连统计数字下方都生硬地印着「来源：」，读起来像给评委看的核查说明书，不像社团官网；
  - **首屏平铺无焦点（后期实验版又走极端挡信息）**：早期稿把简介、活动、新闻、人物七八块内容按同等权重平铺，首屏并排摆两个按钮；后来尝试加交互（`v6`–`v9`）时，AI 又把画圈叉训练神经网络、检索转盘等小游戏塞在首屏最前面，把社团介绍和报名入口挤到了下面；
  - **外链装饰字体水土不服**：直接从外部 Google Fonts 加载站酷庆科黄油体和整套思源黑体网络字库，既显得套路化，在国内校园网或离线打开时还经常加载卡顿、文字跳动。

- **2. 我们的调整方案**：
  - **彻底重写文案语气与出处呈现方式**：删掉正文里所有「根据某某报道整理」式的说明套话，把核验机制改为每条新闻动态与承办成果整条可点击、直接打开通信学院官网原文；正文全部改写成学长学姐面对新同学说话的实在口吻（如「从焊好第一个焊点开始」「全校同学都能来，零基础也行」）；
  - **立下「首屏 1 秒看懂 + 无死按钮报名」硬规矩**：砍掉首屏遮挡信息的小游戏，要求首屏第一眼就呈现社团名称、五类日常活动与醒目的「怎么加入」主按钮；在暂无报名问卷期间，不放灰掉点不动的死按钮，改为一键复制「上海大学通信学院」公众号名称按钮（用隐藏文本框兼容离线与 HTTP 环境），手机端滚过首屏后自动浮现「加入我们」快捷按钮、滚到报名区自动收起；
  - **改为系统正文黑体 + 本地按需分片字库**：去掉全部外部字体 CDN 链接，正文改用与通信学院官网一致的系统自带苹方 / 微软雅黑保证小字号清晰；标题用的思源宋体与数字等宽字体改由自写脚本 `build_fonts.py` 切成轻量 `.woff2` 本地分片放入 `shared/fonts/`（首片仅约 240–260 KB）。

- **3. 为什么要这么改（修改原因）**：
  - 社团成员试看初稿后直接反馈「一股浓浓的 AI 味」，而且大一新同学点进社团官网最关心的是「这社团平时玩什么、零基础能不能去、怎么报名」，在页面正文里解释材料怎么收集来的只会打断阅读，留好可点开的学院官网原文链接就完全满足核验要求；
  - 砍掉首屏挡路小游戏、突出加入主路径后，新同学 3 秒内就能看明白社团特色并复制公众号名称；去掉外部网络字库改成系统黑体配本地分片字库后，无论评委断网双击打开还是同学用校园网手机浏览，都能瞬间加载、不闪字不卡顿。
  - 【待确认：若最终选定滑动交互探索版（如 `v16`–`v19`）作为主参评方案，也可在此补充「针对 `v14/v15` 首屏炫酷但下方仍平铺一划而过的问题，改为吸顶舞台将自然滚屏直接驱动调示波器 / 一刀切开 / 烙铁走线焊接 / 扩散模型去噪」的交互改版案例】

本作品严格遵守原创底线，全部前端页面与交互代码均为独立编写，未搬运他人完整作品或套用商业网页模板。所用外部素材、字体与参考开源项目逐项标注如下：

1. **主办方比赛官方资源包素材**：
   - 社团基础简介与年审资料、社长任捷活动实拍照（`shared/img/renjie.png`，源自官方资源包 `web/任捷_活动照.png`）、社团原有标志（`shared/img/brand/社团logo_*.png`）、上海大学通信与信息工程学院字标（`shared/img/brand/scie-wordmark.png`，源自官方资源包 `web/通信与信息工程学院字标.png`），均来自上海大学人工智能社提供的本次比赛官方资源包。
2. **公开新闻与成果文字来源**：
   - `shared/content.js` 中的 16 条社团活动报道与 3 条承办协办记录，均整理自**上海大学通信与信息工程学院官方网站**（`https://scie.shu.edu.cn/`，同步自「上海大学通信学院」微信公众号）公开报道，每条均保留原标题、发布日期与原文链接；未使用学院报道内的现场照片。
3. **社团吉祥物视觉素材**：
   - `shared/img/ip/` 目录下的吉祥物「小智」（及同系列备选角色「元元」「通通」）各姿态插图、表情图、动图与透明底挂件图，均为本团队在本次大赛 IP 赛道原创设计并借助 AI 画图工具生成，未使用第三方商业插画或模板。
4. **字体来源与开源许可协议**：
   - **思源宋体（`Noto Serif SC`，CSS 字族名 `'SHU Serif'`）**：用于页面大标题、人名与统计大数字，源自 Adobe 与 Google 开源字体项目，遵循 **SIL Open Font License 1.1（开源字体免费许可协议第 1.1 版）**。由 `shared/fonts/build_fonts.py` 切分为本地 `serif-*.woff2` 子集文件，随包附带原版权声明与完整许可协议文本 `shared/fonts/OFL-NotoSerifSC.txt`。
   - **等宽西文与数字字体（`Geist Mono`）**：用于日期、序号与刻度展示（`shared/fonts/GeistMono-latin.woff2`），源自开源项目 `vercel/geist-font`（经 Fontsource 切片，未改动字形），遵循 **SIL Open Font License 1.1**，随包附带完整版权声明与许可协议文本 `shared/fonts/OFL-Geist.txt`。
   - **系统自带字体**：页面正文采用访问设备操作系统自带的 `PingFang SC`（苹方）、`Microsoft YaHei`（微软雅黑）、`Songti SC`（宋体）等系统字体，未打包任何商业受限字库文件。
   - *补充说明*：若最终主参评版本选用早期探索稿 `v1-blueprint`、`v2-sticker`、`v3-riso`，该三版另通过 Google Fonts 引用了 `Noto Sans SC`、`ZCOOL QingKe HuangYou`、`Chakra Petch`、`IBM Plex Mono`，均遵循 SIL Open Font License 1.1；`v5-zhi` 及 `v8`–`v19` 全部仅使用上述本地分片开源字库与系统自带字体。
5. **设计方法参考与线上后台开源组件**：
   - 网页排版自检规范参考开源清单项目 `Hallmark`（`https://github.com/nutlope/hallmark`，MIT 许可协议，仅参考排版检查原则，未复用其代码）；不同候选版本在视觉与动效节奏上曾参考国内外高校技术社团及创意网站思路（如 TreeHacks、MLH、topology.vc、shopify.design 等），全部 HTML / CSS / Canvas / WebGL 代码均为从零手写实现。
   - 线上服务器配套运行的 `club_admin` 管理后台基于开源 Python 框架 `FastAPI` 与 `Uvicorn`（MIT / BSD 许可协议）及 Python 标准库编写，后台前端界面为原生手写代码。
