上海大学人工智能社官网

同一份社团资料（shared/content.js），五种"把往下滑变成一个动作"的官网做法。每一版都是完整官网：社团介绍、活动、新闻、荣誉、师生、加入我们都在，电脑和手机都能看。点卡片进入，往下滑就是交互。

切开v17-slice-r2进入 →

首屏是切水果：电路板、芯片和社团词条抛起来，鼠标或手指划过去切成两半，小心"短路"炸弹。往下滑，一刀切开每一屏；页面最底下能看到你这一趟切下的战利品。
焊接v18-solder-r2进入 →

滑动就是焊一块板：拖焊、插芯片点焊、插排线测通断、合闸，每一节一道工序。合闸后电流走到哪亮到哪，最后屏幕上的小智醒来。
梯度下降v12-contour-r2进入 →

等高线是一张损失函数地图：往下滑就是训练，小球沿梯度一步步滑向谷底，loss 实时下降，收敛处就是"加入我们"。点一下可以放一个新起点。
活动室桌面v20-desk-r2进入 →

滑动就是推着镜头在社团工作台上飞：先拉到整张桌子的全景，再依次俯冲到笔记本、剪报、工牌、手机，每个物件打开一节内容。
折纸飞机v24-fold-r2进入 →

滑动就是把一张招新传单折成纸飞机，字跟着纸被折走。折好后往下滑就是拉弓：滑得越猛飞得越远，也可以按住飞机甩出去。
