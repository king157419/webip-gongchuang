# 人工智能社「共创计划」参赛作品（草稿）

- `web/`：官网三套方案（蓝图 / 贴纸 / 社刊），说明见 `web/README.md`。
- `ip/`：IP 形象三套方案（小智 / 元元 / 通通），含高清图、可打印 STL 与生成脚本，说明见 `ip/README.md`。
- `deliverables/`：三份 IP 提案 PDF（A4 横版，每份 6 页）。
- `_materials/`：主办方资料包解压内容（原样保留）。

选定方案后的打包建议：
- Web 赛道：选定的 `v*/` 目录 + `shared/` + `web/README.md`（作为简要说明）→ `赛道【Web】+队长姓名+队长学号.zip`
- IP 赛道：选定角色的 PDF + 对应 `ip/<角色>/` 高清图 + `ip/3d/<角色>.stl` + `ip/README.md` → `赛道【社团IP】+队长姓名+队长学号.zip`
