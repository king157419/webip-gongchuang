## 一、怎么打开

1. 把压缩包**完整解压**到任意文件夹（不要在压缩软件的预览窗口里直接双击）。
2. 双击最外层的 **`index.html`**，这是入口页，点卡片进入任意一版；也可以直接打开某个版本文件夹里的 `index.html`。
3. 不需要安装任何软件、不需要联网。电脑（1440 宽）和手机（375 宽）都已适配，可以缩小浏览器窗口或用开发者工具切到手机宽度检查。
4. 系统开启"减少动态效果"、或浏览器不支持 WebGL 时，各版会自动退回干净的普通版式，内容不缺。

**压缩包结构**

| 位置 | 内容 |
| --- | --- |
| `index.html`、`_thumbs/` | 入口页和首屏缩略图 |
| `v17-slice-r2/` 等 5 个文件夹 | 5 个官网版本，各自的 HTML / CSS / JS |

## 二、5 个版本：把"往下滑"变成一个动作

访客打开官网都要往下滑。我们没有在首屏放一个挡住信息的小游戏，而是把这个本来就要做的滑动变成一个动作，内容就是这个动作的结果。社团名、一句话介绍和"怎么加入"始终在第一屏。

| 版本 | 滑动就是…… | 亮点 |
| --- | --- | --- |
| **切开** `v17-slice-r2` | 一刀 | 首屏切水果：电路板、开发板、芯片和社团词条从下面抛起来，鼠标或手指划过去切成两半，能看到截面；连续切中、一个不漏才算连击，漏一个或切到"短路"炸弹就断；一刀切中多个另外计分；记录本机最佳和前 5 名。往下滑，一道激光沿切线把首屏整张纸烧开，切口从白热冷却成焦黑；每张内容卡片从一道缝里张开、离开时被激光切成两半。彩蛋：滑到页面最底下，能看到你这一趟切下的所有东西。 |
| **焊接** `v18-solder-r2` | 焊一块板 | 四节四道工序（文字排版按统一规范重做，转场中文字不会出屏）：拖焊、插芯片点焊、插排线测通断、合闸，镜头和节奏各不相同。合闸后电流走到哪亮到哪，灯、芯片、屏幕依次上电，最后屏幕上的小智醒来，直接接到加入的三步。 |
| **梯度下降** `v12-contour-r2` | 训练一步 | 滑第一下，平面等高线图隆起成三维损失曲面，镜头下降、转向，贴进山谷跟着小球走；收敛处打开一个口，穿过去进入正文，后面每节都有分层视差和逐字拼合的标题。小球沿梯度一步步滑向谷底，右下角 loss 实时下降，路上的检查点各接一节内容，收敛处就是"加入我们"。鼠标会顶起曲面，点一下放新起点，有时会卡进局部最低点。 |
| **活动室桌面** `v20-desk-r2` | 移动镜头 | 镜头先拉到整张社团工作台的全景，再依次俯冲到笔记本、剪报、工牌、手机，每个物件先推成铺满画面的近景，再推到一处特写（框外虚化），然后拉回读完；停手后镜头顺势滑一段再停稳。 |
| **折纸飞机** `v24-fold-r2` | 折一下 | 招新传单按真实纸飞机步骤一折一折折起来，传单上的字跟着纸被折走，"怎么加入"印在背面、折成飞机后正好露在机翼上。最后往下滑是拉弓：轻轻滑软软掉下，猛滑飞出画面，也可以按住飞机甩出去；镜头跟拍飞机，地上有米数圈，记录本机最远和前 5 名。 |

## 四、用了哪些 AI 工具、用在哪个环节

| 工具 | 环节 | 做了什么 |
| --- | --- | --- |
| Claude Code | 资料整理、写代码、检查 | 把学院官网 16 篇报道整理成统一字段的 `content.js`；按我们定的方向编写各版本的 HTML / CSS / JavaScript（Canvas 2D、WebGL 着色器、滚动驱动动画）；写字体切片脚本；用无头浏览器在电脑和手机宽度下批量截图，逐帧排查问题 |

## 五、典型修改案例：焊接版"中间过程单调"

| | 内容 |
| --- | --- |
| **AI 原始输出** | 第一版焊接页：每往下滑一段，烙铁就在板子上点一个焊点，四节都是同一个动作，镜头一直平移；结尾只有几根线变亮。我们试看后的意见是"中间的线性过程过于单调，焊好之后要有一个联通、带来成果的感觉"。 |
| **怎么调整** | 第二轮把四节拆成四道真实工序（拖焊 / 插芯片点焊 / 插排线测通断 / 合闸），每道的镜头角度和节奏都不同；合闸后先压暗整块板，电流沿走线一路点亮各个模块，每亮一块弹出一句标注，最后小智在屏幕上醒来，直接接到"加入我们"。复查时还发现一个隐藏问题：页面外层和正文同时设置了横向溢出隐藏，导致"钉在屏幕上"的舞台失效、板子跟着页面滚走，中间动画其实没显示出来——第一次试看时觉得"单调"，有一部分就是这个原因。改成只裁切不产生滚动容器后修好。 |
| **为什么改** | 这个版本想让访客感到"是我焊好了这块板子"。如果每一下都一样，访客只会机械地往下划；工序不同、结尾通电，访客才会感到自己的动作带来了结果，也顺带看懂了社团焊接课在做什么。 |

## 六、素材、字体和开源资源来源

1. **主办方资源包**：社团简介和年审资料、社长任捷活动照（`shared/img/renjie.png`）、社团原标志、通信与信息工程学院字标。
2. **新闻和荣誉文字**：整理自上海大学通信与信息工程学院官网（`https://scie.shu.edu.cn/`）公开报道，每条附原文链接；没有使用报道里的现场照片。
3. **吉祥物"小智"**：本团队在 IP 赛道原创设计、借助 AI 生成的图片，见 IP 赛道作品。
4. **字体**：思源宋体（Noto Serif SC，Adobe / Google，SIL Open Font License 1.1），切成本地分片随包附带，许可文本 `shared/fonts/OFL-NotoSerifSC.txt`；Geist Mono（Vercel，SIL Open Font License 1.1），许可文本 `shared/fonts/OFL-Geist.txt`；正文用系统自带的苹方 / 微软雅黑。
5. **代码**：全部页面和交互代码为本次编写，没有使用前端框架、模板或外部 CDN。设计上参考过 topology.vc、shopify.design 等网站的动效思路，没有复用其代码或素材。
