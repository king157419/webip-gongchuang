# 第二轮修改：所有改版的共同要求（2026-11-18）

项目：上海大学人工智能社官网，静态网页，在 `D:\desk\webip\web\`。每个版本是一个文件夹，共用 `web/shared/`（内容数据在 `shared/content.js`，图片在 `shared/img/`，字体在 `shared/fonts/`）。

你只能改分到你名下的 `*-r2` 文件夹（原版文件夹是对照用的，别动）；不能改 `shared/`。别的 agent 同时在改其他 `-r2` 文件夹，别碰它们。

## 用户是谁、要什么
社团负责人，也是网页赛道的评委，要求很高："我要的是精品网页"，要让人觉得"这是高手做的"，而不是"AI 味"模板。
- 他认可的质感：topology.vc、shopify.design 那一类，滚动驱动的 WebGL、跟手的形变、文字拼合入场、可以拖动的小物件。"炫酷带来的是交互"，但不花里胡哨。
- 核心思路（他自己提的）：访客反正要往下滑，就把滑动变成一个动作，内容是这个动作的结果。不劫持滚动，不挡信息：一分钟内要让人知道这是什么社团、和我有什么关系、下一步怎么加入。
- 字体要有明确的选型，不要系统默认字体或 Noto Sans SC 这种"AI 默认"；排版要有节奏，别平铺直叙。
- 内容只用 `shared/content.js` 里的真实内容，不编数字、不编评价。

## 所有版本都要改的一条：任捷（社长）的照片
现在好几版里，没滑到照片之前照片是黑白的，之后才变彩色。用户说："我支持渐变动画，但是不要从黑白开始变化。"
→ 照片任何时候都不能是灰度，包括动画的起点。入场动画可以从：轻微压暗、轻微模糊、遮罩/切口揭开、位移缩放等开始，但颜色始终是彩色（饱和度不低于 0.9）。照片的静态样式里也不能有 grayscale。

## 做工标准
- 桌面 1440×900 和手机 375×812 都要好看、能用；开启"减少动态效果"时要有能看的退路。
- 控制台没有报错；60fps 级别的流畅度（别每帧做重布局）。
- 改完一定要亲自打开看：评审服务器已经在跑，`http://localhost:8850/<你的文件夹>/`（它服务的是 `web/` 目录）。用内置浏览器时**用 tabs_create 开你自己的新标签页**，别关别人的标签；不行就用 node + playwright 截图。从头滑到尾，截几张关键帧看，有问题就改，改到满意为止。
- 别做成"一个任务式 AI 小游戏挡在信息前面"（v17 的切水果是用户自己点名要的，属于例外，但也不能挡住加入入口和基本信息，见各自任务单）。

## 第三轮补充（2026-11-18 上午，必须遵守）
- 这一轮直接改 `*-r2` 文件夹本身（已经交过一版参赛包，改完会重新打包）。
- **评委是解压后双击 index.html 打开的（file:// 地址，没有服务器）**。这种情况下：不能对外部图片文件做 getImageData / toDataURL / 当 WebGL 贴图读像素（会被浏览器拦）；不能用 fetch 读本地文件；不能用 type="module"。v17、v18 已经用 `zhi-flat-src.js` 把小智图内嵌成数据绕开了这个问题，别删掉。改完必须用 file:// 直接打开测一遍（playwright：`page.goto(Path('D:/desk/webip/web/<文件夹>/index.html').as_uri())`），控制台不能有报错。
- v18 的 html / body 用的是 `overflow-x: clip`（不是 hidden），这是修过的毛病（hidden 会让钉在屏幕上的舞台失效），别改回去。
- 排行榜 / 最高纪录：静态网站没有服务器，只能存在访客自己的浏览器里（localStorage，读写都要 try/catch 包住，存不了也照常能玩），页面上照实写"本机最佳"，别假装是全网排行。
- 别的 agent 同时在改其他 `-r2` 文件夹，只动你自己那个。共用临时目录里别删别人的东西，你的截图放你自己的子文件夹。
